## 🔨 What i have build?

**German Credit Risk Analysis & Prediction**
- This notebook contains exploratory data analysis (EDA) and a predictive machine learning model using the german credit dataset. The project focuses on identifying key risk factors in lending and interpreting model decisions using SHAP values.
- In this small project, I learned how to use EDA and ML to identify key credit risk drivers. By utilizing SHAP to 'open the black box', I provided transparent and actionable insights into the model's decision-making process, demonstrating how specific factors—such as loan duration and amount—directly influence creditworthiness.

🔗 **Project:** [https://github.com/Teme222/german-credit-data-eda](https://github.com/Teme222/german-credit-data-eda)

**Tournament app**
- A Streamlit app for recording and showcasing our friend group’s video game tournaments. We occasionally play FIFA or NHL tournaments, and until now the results have been tracked in Excel. The app now loads all tournament data directly from an Excel file and turns it into a clean, structured, and interactive interface for everyone to browse.
I wanted to create a simple and easy-to-use web app so anyone can check past tournaments whenever they want. More tournaments will be added over time, but the app currently displays only the most recent one.
- In this project, I learned more about Streamlit, how to structure cleaner and more user-friendly pages, how to present data neatly and clearly, how to build a custom point-system with specific rules, and how to process spreadsheet-based data into dynamic, real-time visualizations.

🔗 **Project:** [https://pulina-cup-332256143676.europe-west1.run.app](https://pulina-cup-332256143676.europe-west1.run.app)
